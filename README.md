# SkyWeave 测试网站

这是测试版，图片识别和视频编码在访问者的浏览器内运行。
原图及已保存系列不会随代码上传；当前未提供账号或跨设备作品同步。

发布步骤（注册并登录 GitHub 后）：
1. 新建仓库，名称 skyweave-test，选择 Public。
2. 将本文件夹内的文件上传到仓库根目录，不要只上传 ZIP 或外层文件夹。
3. Settings → Pages → Source：Deploy from a branch。
4. Branch：main，目录：/ (root)，保存。
5. 等发布完成，使用 Pages 页面显示的真实网址。

之后更新对应文件并提交即可更新网站，无需更换地址。
此包包含内置演示点阵；正式推广前请核对示例素材使用权限。
